# 🎟️ EventSphere - Modern Event Management System

![Angular](https://img.shields.io/badge/Angular-21-DD0031?style=for-the-badge&logo=angular&logoColor=white)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-3-6DB33F?style=for-the-badge&logo=spring&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)

EventSphere is a premium, full-stack event and customer management system. It features a highly responsive, modern "Glassmorphism" UI built with **Angular 21 (Zoneless)** and a robust backend powered by **Spring Boot**.

## ✨ Features
* **Interactive Dashboard**: Real-time statistics, total customer count, and upcoming events with a sleek UI.
* **Modern UI/UX**: Premium dark-mode aesthetics with Glassmorphism cards and smooth micro-animations.
* **Real-Time Search**: Instant, zero-latency search filtering for both customers and events.
* **Zoneless Architecture**: Built using the latest Angular 21 Experimental Zoneless Change Detection for maximum performance.
* **Relational Database Management**: Seamlessly connects Customers with Cities and Districts using One-to-Many entity relationships.

## 🚀 Technologies Used
* **Frontend:** Angular 21, TypeScript, HTML5, CSS3
* **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
* **Architecture:** RESTful API, Service Repository Pattern, DTO (Data Transfer Object) mapping.

## 🛠️ Installation & Setup
1. Clone the repository.
2. Run the backend Spring Boot application via IntelliJ IDEA.
3. Navigate to the frontend directory and install dependencies:
   ```bash
   npm install
   ```
4. Start the Angular development server:
   ```bash
   ng serve
   ```
5. Open `http://localhost:4200` in your browser.
